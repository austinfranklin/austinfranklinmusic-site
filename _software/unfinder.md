The Unfinder is a system for improvising music with a personal archive of audio recordings built using FFmpeg on openFrameworks. It analyzes a folder or entire drive of sound files, up to hundreds of thousands, and organizes them into a navigable map by spectral similarity using a self-organizing map that can be reconfigured on the fly. That map is exposed to a small LISP-based live-coding language called PLISP (or PlayLISt Processing), which drives a granular synthesis engine in real time. You can filter what is shown on the map based on sound characteristics and metadata, control audio parameters, and combine the system's navigation logic and scheduler through live code to dynamically shape a performance.

PLISP is a text-based, domain-specific language (DSL) for audio sample manipulation and playlist-based granular synthesis supporting real-time control and live coding. The interface enables command-line interaction with large-scale audio corpora organised on a 2D self-organising map (SOM). It employs LISP-inspired prefix syntax and nested expressions, enabling performers to navigate and manipulate audio material through gesture-based control.
