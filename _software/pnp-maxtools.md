The PnP.Maxtools Library is a set of objects designed for the real-time automation of control parameters within Max, distributed through the Max Package Manager. It's a set of filters, sound description tools, audio effects, and other objects designed to be used together to compose music or improvise without external controllers or hardware, taking incoming audio from a microphone, analyzing it, and using the analysis to automate changes to an audio effect on the incoming signal in real time. **Reflexive Automation** is the term used to describe this analogous relationship between the audio content and the resulting musical transformations.

#### Music Information Retrieval

The sound description tools in the library are real-time music information retrieval algorithms with easily recognizable names — roughness, brightness, hardness, sharpness — correlating to the aural sensation felt while listening to a sound, with output ranging 0–1. Most are subjective descriptors: the output describes a perceived characteristic rather than objectively quantifying it, unlike measurements such as spectral slope or skew which measure the spectra of sounds with no consideration for how listeners perceive them.
