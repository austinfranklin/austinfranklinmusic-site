This project is a method for generating dynamic audiovisual landscapes via wave terrain synthesis (WTS). WTS is a sound synthesis technique that traces a trajectory across a three-dimensional surface, or "terrain," using the resulting height values to generate audio. In essence, WTS uses a 3D surface as a lookup table: coordinates on the terrain serve as inputs, and the height at each point represents amplitude. Reading from a height map is analogous to rolling a ball over a hilly landscape. Both the terrain and the path by which the ball moves over the landscape are defined independently of one another, yet both structures are mutually dependent in finding an outcome, and any changes that occur in either system affect the resulting waveform.
