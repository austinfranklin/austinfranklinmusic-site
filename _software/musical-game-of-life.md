This is an audiovisual project exploring the generation and musification of Life-Like Cellular Automata modeled after John H. Conway's Game of Life, using Magenta's GANSynth Colab Notebook — a cloud-based Jupyter notebook with pre-trained models for synthesizing timbre and audio files. A video and MIDI file of "live" cells are created from variable birth and survival conditions set before generation in Python.

*Not available for download.*
